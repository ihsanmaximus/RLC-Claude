# RLC Website Prototype
Jalankan: buka `index.html` di browser, atau `python3 -m http.server` lalu buka http://localhost:8000. Tanpa backend.
Font memakai Google Fonts (perlu internet; tanpa internet jatuh ke Georgia/system-ui). Semua gambar lokal di `assets/images`.
Lihat `documentation/prototype-notes.md` untuk fitur berfungsi vs simulasi dan batasan.
